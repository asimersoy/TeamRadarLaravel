QGuard helps VALORANT players find a full team using peer conduct feedback, rank, game region and a shared language. Explore the intended experience without an account, API key or game client.

This English walkthrough uses fictional people and tab-local sample state. Do not enter real credentials or personal information. Buttons simulate outcomes; nothing in the walkthrough signs into Riot, forms a real team or enters VALORANT.

What this review demonstrates

Conduct, separate from game skill

Honor comes from teammate conduct ratings. QGuard groups nearby honor scores, then nearby game ranks and waiting time. It does not calculate MMR or replace Riot's skill ranking.

Official data, after opt-in

The planned integration uses RSO and official match data to retrieve only the linked player's observed rank. Players confirm or correct it before queueing. The review values are fictional.

A player creates the game party

The selected host enters a native party code into QGuard. Teammates copy it into VALORANT themselves. Non-friend entry still needs real-player verification after RSO integration.

Local backend, separate demo

The Laravel application has a persistent queue, matcher, sessions, chat and feedback tested with synthetic accounts. This portable walkthrough demonstrates those flows in the browser; it is not a live backend session.

Suggested review order

  1. Account and guest entry

    Choose the guest option, complete sample setup and use the sample connection control. No real signup or Riot credentials are needed.

  2. Linking disclosure and rank confirmation

    Review planned data sharing, then compare observed and declared rank. Also inspect unavailable rank and declined linking. Failure screens illustrate states; the live retry/fallback contract remains pending.

  3. Queue and accept a team

    Use the sample team-formation control, accept your offer, then use the sample peer-acceptance control within the twenty-second window. These controls replace other reviewers for the demonstration.

  4. Party handoff and private text

    Enter a fictional code such as SAMPLE-CODE. Inspect the recipient view, roster check and session-end controls. A sample peer control demonstrates the three-request closure; otherwise the five-minute timer applies.

  5. History and required feedback

    After closing the sample session, rate eligible teammates. Each submitted card locks; incomplete feedback blocks the next queue. Optional sliders do not affect matching.

  6. Private summaries and reports

    Compare a teammate's view with your own summaries, then inspect reporting. The admin example is fictional evidence, not administrative account access.

Use “Reset sample” in the walkthrough's top bar to start again. “All screens” opens the state catalog. Direct screen links are review shortcuts; a complete journey starts with the guest entry.

Before normal player use

Live RSO, API rank retrieval and per-player consent enforcement still need implementation after provider access. Real-player party-code tests and release checks follow. Discord, voice recording and desktop/client automation are outside this review scope.

The intended first release is 18+, EU game region, with English and Turkish interfaces. This artifact does not open registration or matchmaking.
