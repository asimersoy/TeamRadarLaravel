Serve this `qguard-review/` directory with a local static HTTP server so the
source prototype can load its sibling brand assets. No dependencies are required. The prototype is not the production frontend and does not select the
application stack. Review controls live in a separate top strip. Use All screens
to open any page/state and Reset sample to restore fictional data. The
current palette is applied on every page. Earlier visual modes are retained in
the historical study, not offered as current product choices. Browser storage
contains synthetic prototype state only; never enter actual credentials/data.

Every product button performs a local demonstration, navigates to another
sample state or explains an unavailable live action. The prototype cannot
authenticate a Riot account, match real users, enter a game or create Discord
rooms. Guest/admin preview is reviewer navigation, not production authorization.

The checkpoint packet and verification record are linked from the
[work record](../../planning/design-checkpoint.md). Outstanding policy proposals
remain in [the spec packet](../../specs/review-version/proposals.md).

## Local Preview

Open `qguard-review.html` in a local browser, or from this repository run:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory project-docs/design/qguard-review
```

Then open `http://127.0.0.1:8765/prototype/index.html#review`. Stop that terminal server with Ctrl-C
after review. The in-app browser allows HTTP preview but rejected direct `file:`
navigation; standalone direct-file execution is not part of the passed checks.
The loopback preview may remain running for owner review; the current-state
record identifies the active handoff.

The standalone file is generated by [build-standalone.py](build-standalone.py):

```sh
python3 project-docs/design/qguard-review/build-standalone.py
```

The builder also packages the same HTML in `qguard/resources/review/` for the
application guest entry. Edit the source HTML/CSS/JS and brand files, then regenerate. The standalone
copy embeds CSS, JS, outlined logo SVGs and icons. No CDN or remote font is loaded.
The source image assets remain independently reusable. Local storage remains
fictional preview state, not production persistence or authorization.
