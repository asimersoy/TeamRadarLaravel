# Historical QGuard Palette Samples

These files preserve the A/B/C comparison shown before DEC-073. A was selected
and then calibrated; open the [current prototype](../qguard-review.html) for the
approved design. The older forest token values are not current requirements.

`baseline.html` freezes the accepted light prototype used to generate the study
at `7f21b91`. `build.py` reads that snapshot, never the evolving current design.
`palettes.json`, earlier screenshots and contrast records describe this study.
Entry pages and review bars identify the samples as archived.

Rebuild with `python3 project-docs/design/qguard-review/color-study/build.py`.
This regenerates HTML only; recorded screenshots remain historical evidence.
