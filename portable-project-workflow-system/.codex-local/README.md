# Local Execution Scratch

This ignored directory may hold volatile execution details that help a worker
resume after compaction, interruption, or terminal-session loss.

\`current-task.md\` may be rewritten freely, but it is never authoritative. It
must not be the only location for decisions, approvals, requirements,
blockers, deferred work, review gates, completion evidence, credentials,
personal data, or production data. Promote durable facts to tracked records
before a commit, handoff, intentional stop, or completion report.
