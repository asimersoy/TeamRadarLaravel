# Historical Evidence

Files in this directory preserve completed, superseded, or chronological
evidence. They cannot select the current workflow, worker, scope, approval
state, or next action.

Before using historical evidence:

1. start from `AGENTS.md` and the mandatory documentation entry path;
2. identify the current authoritative record that links here;
3. state the provenance or regression question being investigated;
4. do not edit a completed report to resemble current state;
5. record any current conclusion in the appropriate project record rather than
   inside the historical artifact.

Append-only logs belong here when chronological evidence is genuinely useful.
Long-form artifacts belong in their designated files; logs should contain
concise references, scope, outcomes, and discrepancies.
